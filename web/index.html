Shamir Secret Sharing

Split an integer into shares over a prime field, then reconstruct it by Lagrange interpolation. All calculations run in this browser tab; no server API is called.

Educational use only. Do not enter production keys or sensitive secrets. This demonstrates Shamir splitting, not authenticated verifiable secret sharing, distributed key generation, or a complete multiparty-computation protocol. A reconstructed number cannot be authenticated without an independent trusted check.
